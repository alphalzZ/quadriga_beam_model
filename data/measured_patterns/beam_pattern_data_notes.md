| 项目 | 内容 |

## 2. 坐标系与扫描范围

### 2.1 坐标系：球坐标 (θ, φ)

- **θ = 极角（离轴角）**，从**固定参考轴**（阵面法线，星上通常取对地轴）起算，**只提供 0°~90°**，即仅**前半空间（一个半球）**。
- **φ = 方位角**，绕该参考轴旋转，0°~359°。

固定 θ 时，φ 从 0° 扫到 360° 画出的是一圈**等离轴角小圆**（圆锥截线），**不是**绕着天线硬件转一圈；θ 每变一次，这圈圆换一个高度（θ=0 缩为轴顶点，θ=90° 张成赤道面）。

### 2.2 为什么不会"绕到天线背面"

θ 上限为 90°，数据集本身就是一个半球面，**θ > 90° 的背面完全没有数据**。

数据佐证：

- **θ=90° 整行贴底**：346/360 个点 ≤ −59.99 dB，基本落在 −60 dB 钳位上——正是阵面掠射的物理表现。
- **θ 不是从波束轴起算**：若 θ 相对波束指向，则所有文件峰值都应在 θ=0。实测峰值位于 (Pitch, Azimuth)，例如 `Pitch_20_Azimuth_210` 峰值在 θ=20°、φ=210°，此时 θ=0 处已掉到约 −41 dB。说明 θ 的零点是一根**固定轴**，波束被偏转到最大 50°。

### 2.3 为什么每个 θ 都要 360° 一整圈

波束偏轴（最多 50°），且方向图**在 φ 上不对称**：同一 θ 下沿 φ 走一圈，增益起伏可达 33.2 dB（θ=10° 行 max−min）。要完整描述偏轴波束的截面，必须每个 θ 扫满一圈。

## 3. 数据判读：78 个文件是什么

### 3.1 峰值位置规律

每个文件的增益峰值都落在其**文件名标注的 (Pitch, Azimuth)** 处：

| 文件 | 峰值位置 | 说明 |
|---|---|---|
| `Pitch_0_Azimuth_0` | θ=0°, φ=0°（φ 在极点退化） | 峰值行全为 0 dB |
| `Pitch_20_Azimuth_210` | θ=20°, φ=210° | 精确吻合 |
| `Pitch_50_Azimuth_90` | θ≈49°, φ=90° | 与标注差 1°（栅格/峰值展宽） |

这说明 78 个文件共用同一角度网格，每个文件对应一个**波束指向状态**。

### 3.2 78 套波束权（而非 78 个独立设计的波束）

对 `Pitch=0` 的 13 个文件（指向相同、峰值同在极点）分区比较：

| 区域 | 文件间差异（RMS） |
|---|---|
| 主瓣（θ ≤ 4°） | **0.15 ~ 0.34 dB**（基本一致） |
| 副瓣（θ = 10°~40°） | **4.0 dB** |
| 远副瓣（θ > 40°） | **3.3 dB** |

结论：**同一指向、主瓣相同、副瓣结构不同** → 对应**不同的权值（相位分布）设置**。
即 78 个文件 = 78 套波束权状态：`Pitch=0` 组是"同指向、不同权"，其余是"指向与权值同时变化"。

方位并非简单的绕轴旋转：`Pitch_0_Azimuth_a` 与 `Pitch_0_Azimuth_0` 做 ±a 方位平移后仍差 3.4~9.4 dB，说明权值变化不等价于几何旋转。

### 3.3 波束形状随指向的退化

将每个文件按"到自身峰值方向的角距"归一化后：

- 径向轮廓整体一致（峰值 0 dB → 90° 处约 −62 dB）；
- 但随 Pitch 增大逐渐偏离参考（RMS 0.37 dB @ Pitch=0 → 8.9 dB @ Pitch=50）。

符合**固定阵面电扫离轴**的特征：扫描角越大，波束展宽、增益下降（扫描损失）。

## 4. 数据来源判断：仿真 vs 暗室实测

结论：**不是暗室原始实测数据**，更像"仿真（或实测后插值到规则网格）+ 后处理"。依据：

| 指纹 | 实测值 | 含义 |
|---|---|---|
| −60 dB 硬钳位 | 每文件 5.6%~22.2% 的点**精确等于** −60.00 dB；`Pitch0_Azi0` 共 7,284 点（22.2%） | 真实噪声不会整片堆在同一值上；分布直方图在 −60~−55 dB 区间出现异常尖峰（35.5%） |
| 20 个 −65 dB 点 | 每文件**恰好 20 个**，且**位置完全相同**：θ=89 的 φ=0/89/90/91/180/269/270/271；θ=90 的 φ=0/1/89/90/91/179/180/181/269/270/271/359 | 全部落在 φ≈0/90/180/270 的坐标轴奇异点，78 个文件复现同一位置，实测不可能 |
| 数值栅格 | 全部严格为 0.01 dB 的整数倍 | 导出时统一取整 |
| 平滑度 | 小角度处沿 φ 的二阶差分中位数 0.00~0.01 dB | 几乎无测量纹波 |
| 数据规模 | 78 × 32,760 ≈ 255 万点 | 按 0.5 s/点，单组约 15 天连续暗室时间，四组数据需数月 |

> 若是暗室实测，常规做法是测若干切面（φ=0/45/90/135…）后插值，不会给出每 1°×1° 全半球 × 78 组的规模；且 −60 dB 附近应为噪声起伏而非齐平。

## 5. 使用建议

1. **选文件**：按卫星/波束的指向状态选对应 `Pitch/Azimuth` 文件；指向落在网格之间需插值（Pitch 10° 步进、Azimuth 30° 步进，插值误差需评估）。
2. **查增益**：由视线方向与参考轴的夹角算 θ、绕轴方位算 φ，在对应文件内查表；注意 θ 是**相对固定参考轴**，不是相对波束轴。
3. **避开钳位区**：−60 dB 以下的值是钳位值而非真值，做干扰/副瓣分析时不可当真值使用。
4. **避开奇异点**：θ=89°~90° 且 φ≈0/90/180/270 的 20 个点（值为 −65 dB）为数值奇异点，不可直接当增益使用。
5. **归一化**：数据为归一化方向图（0 dB = 峰值），链路预算需叠加天线峰值增益（dBi）才得绝对增益。
