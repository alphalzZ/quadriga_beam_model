# 四邻居转换插值的留一验证

验证 [make_allfit_link_arrays.m](../time_domain/make_allfit_link_arrays.m) 中的方法：把四个相邻扫描状态的**完整功率图**旋转到目标指向，再在线性功率域加权。验证对象是 78 个实测状态中的已测波束：先把其中一个当作未知波束（beam_a），只用它的四个邻居（beam_w/x/y/z）插值，然后和它真正测得的方向图比较。

## 设计

- **真值**：78 个实测文件中的 beam_a 本身，不使用任何模型输出。
- **邻居**：以 beam_a 为中心的四个状态，俯仰 ±10°、方位 ±30°，权重各 0.25。beam_a 本身不进入插值。
  例：beam_a = Pitch 20°/Azimuth 90°，邻居为 (10,60)、(10,120)、(30,60)、(30,120)。
- **留出集**：俯仰 10°、20°、30°、40° × 方位 0°…330°，共 **48 个状态**。
- **不纳入**：俯仰 0° 和 50° 的 26 个文件。它们在一侧没有邻居，不能用居中的四邻居结构留出。方位 360° 与 0° 逐格相同，只作为 0° 使用。
- **比较对象**：同一网格（θ=0…90°，φ=0…359°，1° 步进）上的预测 dB 与实测 dB。
- **基线**：(a) 不做旋转、直接对 dB 加权平均；(b) 不做旋转、线性功率加权平均。两者用来说明旋转本身的作用。

## 实现核对

- `validate_four_neighbor_interp.py` 是 `make_allfit_link_arrays.m` 插值部分的逐行 Python 移植（最小旋转 `align_rotation`、`interp2` 线性插值并在范围外填 0、`tq>90` 视为后半球不存在的数据）。
- **与 MATLAB 直接对照**：在 Octave 8.4 中运行 QuaDRiGa 源码（`fraunhoferhhi/QuaDRiGa`）和原函数 `make_allfit_link_arrays(45.43,188.62,'RHCP')`，导出 `info.power_grid`（`export_octave_reference.m`）。Python 移植对同一目标、同一角点、同一权重的线性功率最大偏差为 **5.0×10⁻¹⁵**，与 Octave 结果一致。
- 校准表 `calibration_tables.mat` 中的 `baseline_db + residual_db` 与 78 个 txt 文件的最大偏差为 **7.1×10⁻¹⁵ dB**，即两者是同一份实测数据。

## 结果

下表为 48 个留出状态的统计（中位数 / 最差）。“最差”指误差最大的那个状态。

| 指标 | 本方法（转换+线性功率） | dB 直接平均（无转换） | 线性平均（无转换） |
|---|---:|---:|---:|
| 实测 ≥ −3 dB 区域 RMS 误差 (dB) | **0.11** / 0.23 | 32.3 / 38.6 | 26.8 / 35.2 |
| 实测 ≥ −10 dB 区域 RMS 误差 (dB) | **0.25** / 0.49 | 29.5 / 34.4 | 23.5 / 30.4 |
| 实测 −10～−20 dB 区域 RMS (dB) | **0.96** / 2.94 | 15.6 / 20.1 | 10.7 / 16.1 |
| 实测 −20～−40 dB 区域 RMS (dB) | **4.55** / 6.84 | 9.4 / 11.1 | 8.6 / 10.8 |
| 实测 < −40 dB 区域 RMS (dB) | 6.57 / 9.00 | **5.92** / 6.75 | 8.18 / 10.56 |
| 全半球加权 RMS (dB) | **6.32** / 8.54 | 6.65 / 8.06 | 8.32 / 10.54 |
| 峰值电平误差 (dB) | **−0.005** / −0.055 | −19.8 / −25.3 | −6.0 / −6.0 |
| 峰值方向误差 (°) | **0** / 1.0 | 12.5 / 25.5 | 14.1 / 19.7 |
| −3 dB 区域立体角比（插值/实测） | **1.00**，范围 0.94～1.04 | 0（无 −3 dB 区域） | 0（无 −3 dB 区域） |
| −3 dB 区域交并比 IoU | **0.97**，最小 0.86 | 0 | 0 |

主要结论：

1. **主瓣和 −10 dB 以上区域可以准确复现**。48 个状态中，实测 ≥ −10 dB 区域的 RMS 误差最大只有 0.49 dB，峰值方向误差最大 1°，−3 dB 区域形状基本一致。
2. **旋转是必要的**。不旋转的两种平均都会把错开的主瓣混在一起，峰值低 6～25 dB，主瓣 RMS 误差达到 20～30 dB。
3. **误差集中在旁瓣和零陷**。实测 −10～−20 dB 区域的 RMS 约 1 dB，−20～−40 dB 约 4.5 dB，低于 −40 dB 的零陷约 6.6 dB。这些区域在全半球 RMS 中占主导，所以全半球误差（约 6.3 dB）看起来比主瓣大得多。
4. **在低于 −40 dB 的区域，直接 dB 平均略好**（中位数 5.9 dB 对 6.6 dB）。原因尚未单独验证，推测是线性平均会保留邻居的旁瓣结构，而这些结构与 beam_a 的零陷并不对齐。这一点不影响主瓣的结论，但说明本方法在深零陷的位置上并不精确。
5. **俯仰 40° 的误差最大**。图 `loo_summary.png` 显示，俯仰 40° 行的留一误差高于 10°～20° 行。推测原因是这一行的邻居位于 50° 边界附近，但这里没有做进一步分析来确认。

## 方法的边界

- **只验证功率（幅度）**，不验证相位。插值使用的复相位来自物理基准的假设，实测文件没有相位。
- **只验证 10°×30° 的邻居间距**。这是测量网格的间距，结论不能直接外推到更稀的状态网格。
- **真值是网格上的实测点**。C1 `(45.43°,188.62°)` 不在测量网格上，没有实测真值，因此不能作为验证对象，只能用于与 MATLAB 对照的一致性检查。
- **俯仰 0° 与 50° 未验证**，因为它们缺少一侧的邻居。
- **“比较一致”不等于真实天线就是这样**。这里验证的是插值方法对已测状态的重建能力，而不是新的测量。

## 复现

```bash
# Python 验证（需要 numpy、scipy、matplotlib）
cd experiments/measured_array_1970/interp_validation
python3 validate_four_neighbor_interp.py

# Octave 参考（需要 QuaDRiGa 源码路径）
octave --no-gui --eval "export_octave_reference('/path/to/QuaDRiGa/quadriga_src')"
```
